# Дополнительные секции правил

Загрузчик читает `rules.json`, затем `rules.d/*.json` по алфавиту имён файлов.
Каждый файл содержит JSON-объект с новыми ключами верхнего уровня, например
`router.json`:

```json
{
  "router": {
    "jev_down": "deep"
  }
}
```

Новые секции (`router`, `proactive`, `complaint`, `emoji`, `events`, `personal`)
добавляйте здесь. Ключ, уже объявленный в `rules.json` или другом файле,
вызывает ошибку загрузки, даже если значения совпадают. Вложенные объекты
не сливаются. Существующие секции меняйте в файле, где они объявлены.

Каталог может отсутствовать или быть пустым. Файлы без расширения `.json`
не читаются. Движок получает объединённый словарь `SkillPackage.rules`.
