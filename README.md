# О!дин запрос — AI-агент путешествий для Островка

Человек пишет одно сообщение («к тёплому морю в ноябре вдвоём, до 150 тысяч»). Агент ведёт его от идеи до корзины и имитированной оплаты: вдохновение → выбор направления → подбор и сравнение (перелёты или поезда, отели, трансферы) → сборка с проверкой стыковок → корзина → покупка → жизнь после покупки.

> Статус: идёт сборка гибридной версии (2026-10-28). Работа ведётся через [issues](https://github.com/all0b0y/search_travel/issues); итоговый README будет в конце.

## Как устроено

- **Быстрый путь (2–4 с).** Код сразу ищет в моке Островка и открытых данных и собирает 3 варианта: дешевле / быстрее / комфортнее, с рисками и «чем пожертвовали».
- **Глубокий путь (до 30 с).** Если запрос с подтекстом или компромиссом, открытая модель думает и зовёт те же инструменты: пересобрать, найти экономию, проверить дорогу, найти направления.
- **Цифры пишет код.** Модель не придумывает цены, время и итоги, код проверяет каждый ответ перед показом.
- **Покупку делает человек.** Корзина, оформление и оплата работают только по кнопке.

Схема — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Решения и технический контракт — [`AGENT_PLAN.md`](AGENT_PLAN.md). План работ — [`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md).

## Данные — честно

- **Реальные:** направления, отели (названия и координаты), районы и достопримечательности (OpenStreetMap), климат (Open-Meteo), аэропорты (OurAirports), маршруты (OpenFlights).
- **Синтетические:** цены, наличие, расписания, правила отелей, спрос (`insights`), скидки и события. Синтетика детерминированная, в данных помечена `source = synthetic`.
- Островок не даёт API, поэтому всё это отдаёт «мок Островка» — MCP-сервер `ostrovok_mcp/`. Его можно заменить настоящим API без изменений в остальном коде.

## Запуск

```sh
uv venv --python 3.11 .venv && uv pip install -r requirements.txt
cp .env.example .env                                            # OPENROUTER_API_KEY
.venv/bin/python -m agent.server --debug --flags stage3,guide   # http://127.0.0.1:8787/debug
.venv/bin/python -m agent.server --fixtures                     # без модели: ответы-фикстуры договора
.venv/bin/python -m pytest tests -q                             # юнит-тесты, без сети и моделей
```

## Структура

```
agent/              движок: состояние, ход, шаги, ранжирование, проверки, гид, HTTP API
ostrovok_mcp/       мок Островка (MCP): каталог, цены, корзина, заказы, insights
data/               базы SQLite (открытые данные + каталог мока)
data_build/         офлайн-сборка баз
skills/trip-agent/  промпты, тон, правила, схемы карточек
evals/              кейсы, сценарии, персона, судья, отчёты
tests/              юнит-тесты
web_debug/          отладочная страница
```
